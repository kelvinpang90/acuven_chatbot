## 本文件的约定

1. 一个 session 做一个编号任务：读本文件 → 做完 → 验收 → 开 PR，中途不需要逐步审批。
2. **对计划本身有异议时才停下来讨论**，不要在每个任务上重新走一遍「先计划、等确认」。
3. 做完把 `[ ]` 改成 `[x]`，并在该任务下补一行记录：做了什么、偏离了什么、验证到什么程度。复选框只允许 `[ ]` / `[x]`。
4. 本文件里**没有**的工作（临时需求、探索型任务）才需要先写计划、等确认。
5. 任务编号 `CHAT-TASK-NNN`（OpenClaw `project_id` 为 `chatbot`）。阶段 0 的拆分草案在
   [docs/product/DESIGN.md](product/DESIGN.md) 第 13 节；登记一项时按当时的代码重新核对路径，写进 `.platform/tasks.yaml`，
   再把下面对应的「待登记」行换成带编号的一行。
6. 合并 Chatbot（E-21）之前的历史任务记录冻结在 [tasks/todo.md](../tasks/todo.md) 与 [tasks/todo-v1-mvp.md](../tasks/todo-v1-mvp.md)，只读不续写（Q-25）。
